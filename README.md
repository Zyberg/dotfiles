# Dotfiles for ...

This repo contains more or less everyting that I need from my system set up in a declarative way. Currently using NixOS, but trying to keep my `.config` files outside `.nix` for greater cross-platform support.

## Tech

This info is also readily accessible from my `home-manager/home.nix` file, but here we go...

| Tooling  | Package Name |
| ------------- | ------------- |
| Distro  | [NixOS](https://nixos.org/)  |
| WM  | [Hyprland](https://hyprland.org/)  |
| Terminal | [Kitty](https://sw.kovidgoyal.net/kitty/) |
| Shell | [zsh](https://www.zsh.org/) |
| Notification Daemon | [Dunst](https://github.com/dunst-project/dunst) |
| App Drawer & more | [Tofi](https://github.com/philj56/tofi) |
| Text Editor | [Neovim](https://neovim.io/) |
| Clipboard Manager | [Clipse](https://github.com/savedra1/clipse?tab=readme-ov-file) |
